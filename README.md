# 4Ray | 4A Engine Recreation Project

Этот проект нацелен на примерное воссоздание движка 4A Engine версии 3322 за 6 августа 2014. Репозиторий создан исключительно из научного интереса.

# Сборка
1. Установить Visual Studio 2026.
2. Открыть решение `trunk\uEngine.slnx`.
3. Выбрать конфигурацию `Release`.
4. Сборка -> Собрать решение

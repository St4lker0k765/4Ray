# 4Ray | 4A Engine Recreation Project

Этот проект нацелен на примерное воссоздание движка 4A Engine версии 3322 за 6 августа 2014.

## ДИСКЛЕЙМЕР: Репозиторий НЕ включает в себя игровые ресурсы из Metro 2033 Redux и/или Metro Last Light Redux, а также репозиторий никак не связан со студией 4A Games.

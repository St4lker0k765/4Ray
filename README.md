# 4Ray | 4A Engine Recreation Project

Этот проект нацелен на примерное воссоздание версии 4A Engine, использованного в Metro 2033 Redux и Metro: Last Light Redux.

## ДИСКЛЕЙМЕР: Репозиторий НЕ включает в себя игровые ресурсы из Metro 2033 Redux и/или Metro Last Light Redux. Также репозиторий никак не связан со студией 4A Games и их издателем Embracer Group.
